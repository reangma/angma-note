가장 큰 그림 한 장

AI 모델은 결국 “입력을 넣으면 정답을 맞히도록, 안에 든 숫자(가중치 weight)를 조금씩 고쳐 나가는 기계”예요. 사진을 넣어 “강아지!”라고 답하고, 틀리면 숫자를 살짝 고치고… 이걸 수없이 반복하는 게 학습(training)입니다.

오늘 배우는 4가지는 “어떤 데이터를 잘 다루느냐”로 나뉩니다.
· CNN → 이미지(사진)처럼 공간(위치)이 중요한 데이터
· RNN · LSTM · GRU → 순서가 중요한 데이터(시간 순서, 문장 속 단어 순서)

그리고 셋의 관계는 한 줄로 끝납니다: RNN(기본·기억력 짧음) → LSTM(기억 보강) → GRU(LSTM 간소화). 이 흐름만 잡고 들어가면 절반은 먹고 들어가요.

시험 포인트 학습의 3단계는 어떤 모델이든 똑같습니다 — ① 순전파(Forward)로 예측 → ② 손실(Loss) 계산(정답과의 차이) → ③ 역전파(Backward)로 기울기 구해 가중치 업데이트(경사하강법, Gradient Descent).
🐣 처음이라 단어가 어렵다면 걱정 마세요. 모르는 단어(ReLU, 가중치, 텐서 등)가 나오면 바로 아래 📖 쉬운 용어사전에서 찾으면 됩니다. 위쪽 메뉴의 📖 용어사전을 누르거나, 사전 안의 검색창에 단어를 쳐도 돼요. 먼저 용어사전을 한 번 쭉 훑고 본문을 읽으면 훨씬 쉬워요.

🧱 가장 기초 (AI가 ‘배운다’는 게 뭐야?)

신경망 Neural Network

사람 뇌의 신경세포가 이어진 모습을 흉내 낸 계산 구조. 숫자들이 여러 ‘층’을 지나며 입력 → 답으로 바뀝니다.

가중치 Weight

각 연결이 얼마나 중요한지를 나타내는 숫자. AI가 학습하면서 이 숫자를 계속 바꿔 답을 맞춰가요. 즉, AI가 ‘배우는’ 대상이 바로 이 가중치예요.

편향 Bias

결과를 살짝 위/아래로 옮겨 주는 보정값. 비유: 저울 영점 조절 나사 같은 것.

파라미터 Parameter

AI가 학습으로 정하는 숫자들(가중치 + 편향)을 통틀어 부르는 말.

학습 Training

수많은 예시를 보며 가중치를 조금씩 고쳐 정답을 잘 맞히는 상태로 만드는 과정. 비유: 문제집을 반복해 풀며 실력을 키우는 것.

순전파 Forward

입력을 넣어 답을 앞으로(→) 계산해 내는 과정.

손실 / 손실함수 Loss

AI의 답이 정답과 얼마나 틀렸는지 나타내는 점수. 작을수록 좋아요.

역전파 Backpropagation

틀린 정도(손실)를 거꾸로(←) 따라가며 “어느 가중치를 얼마나 고쳐야 할지”를 계산하는 과정.

기울기 Gradient

가중치를 어느 방향으로 바꾸면 손실이 줄어드는지 알려주는 화살표(방향 + 세기).

경사하강법 Gradient Descent

기울기 화살표를 따라 손실이 낮아지는 쪽으로 한 걸음씩 내려가며 가중치를 고치는 방법. 비유: 안갯속 산에서 가장 낮은 골짜기를 더듬어 내려가기.

학습률 Learning rate (η)

한 번에 얼마나 크게 고칠지 정하는 보폭. 너무 크면 휙휙 지나치고, 너무 작으면 느려요.

텐서 Tensor

숫자들을 여러 줄·여러 칸으로 쌓아 놓은 숫자 덩어리. 컬러 이미지 = 가로 × 세로 × 색(3) 의 3차원 텐서.

과적합 Overfitting

연습문제(훈련 데이터)만 달달 외워서, 처음 보는 시험문제(새 데이터)는 못 푸는 상태.

과소적합 Underfitting

아예 충분히 못 배워서 연습문제조차 못 푸는 상태.

분산 Variance

모델이 데이터에 따라 답이 들쭉날쭉한 정도. 앙상블로 이걸 줄이면 더 안정적이에요.

⚡ 활성화 함수 (숫자를 한 번 변형하는 규칙)

활성화 함수 Activation

뉴런을 통과하는 숫자를 한 번 변형해 주는 규칙. 이게 있어야 AI가 복잡한(구불구불한) 패턴을 배울 수 있어요.

ReLU 렐루

음수는 0, 양수는 그대로! 아주 간단한 규칙. “나쁜(음수) 신호는 끄고 좋은 신호만 통과”. 딥러닝에서 가장 많이 쓰는 활성화 함수.

시그모이드 Sigmoid (σ)

어떤 숫자든 0~1 사이로 눌러주는 함수. ‘얼마나 열까(0~100%)’ 같은 비율을 표현할 때 써요. LSTM 게이트가 이걸 사용.

tanh 하이퍼볼릭 탄젠트

어떤 숫자든 −1~1 사이로 눌러주는 함수. 음수도 표현 가능. LSTM의 ‘새 기억 후보’를 만들 때 사용.

Softmax 소프트맥스

여러 점수를 합이 100%인 확률로 바꿔주는 함수. “강아지 94%, 고양이 4% …”처럼 만들 때 맨 마지막에 써요.

비선형성 Non-linearity

직선이 아닌 구불구불한 관계도 표현할 수 있는 성질. 활성화 함수가 이걸 만들어 줍니다.

🎯 문제 종류 · 점수 매기기

회귀 Regression

숫자(연속값)를 맞히는 문제. 예: 내일 기온은 몇 도?

분류 Classification

종류(카테고리)를 맞히는 문제. 예: 강아지냐 고양이냐?

MSE 평균제곱오차

정답과 예측의 차이를 제곱해 평균 낸 손실. 회귀(숫자 맞히기) 문제에 사용.

Cross Entropy 교차 엔트로피

분류 문제에서 쓰는 손실. 정답 종류에 확률을 얼마나 잘 줬는지로 점수를 매겨요.

Top-5 오류율 Top-5 error

AI가 뽑은 유력 후보 5개 안에 정답이 없으면 틀린 걸로 치는 평가 방식. 낮을수록 좋음.

ImageNet / ILSVRC 대회

1000종 사진을 분류하는 유명한 AI 대회. 2012년 AlexNet 이후 CNN(딥러닝)이 휩쓸었어요.

🖼️ CNN 용어 (사진 보는 AI)

합성곱 Convolution

작은 ‘도장’(필터)을 그림 위에서 한 칸씩 밀며 찍어, 위치마다 특징을 뽑아내는 계산.

필터 / 커널 Filter / Kernel

그림에서 특정 무늬(세로줄·둥근 모양 등)를 찾는 작은 도장. 이 도장 속 숫자가 AI가 학습하는 대상.

특징 맵 Feature Map

필터로 찍어 나온 결과 그림. “여기에 그 무늬가 얼마나 있나”를 보여줘요.

채널 Channel

색의 개수. 흑백 = 1, 컬러(RGB) = 3. 층이 깊어지면 ‘특징의 종류 수’를 뜻하기도 해요.

스트라이드 Stride

도장을 한 번에 몇 칸 옮기는지. 크게 하면 결과 그림이 더 작아져요.

패딩 Padding

그림 테두리에 0을 둘러주는 것. 가장자리 정보를 살리고 크기를 유지하려고 합니다.

풀링 Pooling

그림을 작게 요약하는 단계. 2×2에서 가장 큰 값만 남기면 Max, 평균이면 Average. 학습하는 숫자가 ‘없는’ 층이에요(시험 단골!).

Flatten 평탄화

여러 줄짜리 특징을 한 줄로 쭉 펴는 것. 마지막 판단(FC층)에 넣기 위해서요.

완전연결층 FC layer

모든 입력을 다 연결해 최종 답을 내는 보통의 신경망 층.

지역성 Locality

멀리 떨어진 픽셀까지 다 보지 않고 ‘주변 일부만’ 보는 성질. 위치 정보를 지켜줘요.

가중치 공유 Weight Sharing

같은 필터(도장)를 그림 전체에 재사용하는 것. 덕분에 학습할 숫자가 확 줄어요.

수용 영역 Receptive Field

결과 한 칸이 원본 그림에서 실제로 보고 있는 넓이. 층을 거칠수록 넓어져요.

1×1 합성곱 1×1 conv

한 칸짜리 도장. 위치는 안 보고 여러 채널(특징)을 섞어 개수를 줄이는 용도. 계산량을 아껴줘요.

GAP Global Average Pooling

각 특징 맵을 통째로 평균 1개로 줄이는 것. 마지막에 써서 과적합을 막아요.

배치 정규화 BN

층마다 숫자들의 크기를 적당히 고르게 맞춰주는 기법. 학습을 빠르고 안정적으로 해줘요.

데이터 증강 Data Augmentation

사진을 뒤집고·자르고·키워서 데이터를 뻥튀기하는 것. 더 다양하게 배워 과적합을 막아요.

드롭아웃 Dropout

학습할 때 뉴런 일부를 일부러 꺼버리는 것. 특정 길에만 의존하지 않게 해 과적합을 막아요.

보조 분류기 Auxiliary Classifier

신경망 중간에서도 답을 내보게 해서, 깊은 망 학습을 도와주는 장치(Inception에서 사용).

스킵 연결 Skip-connection

입력을 한두 층 건너뛰어 그대로 더해주는 지름길. ResNet의 핵심.

잔차 학습 Residual Learning

전체가 아니라 ‘바뀌는 양(차이)’만 배우게 하는 방식. 학습이 훨씬 쉬워져요.

항등 매핑 Identity mapping

입력을 그대로 출력으로 내보내는 것(변화 없음). “필요 없는 층은 그냥 통과”를 표현해요.

병목 Bottleneck

1×1로 채널을 줄였다가(좁힘) → 3×3 → 다시 1×1로 늘리는(넓힘) 구조. 계산을 아끼려고. 깊은 ResNet에서 사용.

학습 저하 Degradation

망을 너무 깊게 했더니 ‘훈련 성적조차’ 더 나빠지는 현상. 과적합과 달라요(과적합은 시험 성적만 나쁨).

Loss Landscape 손실 지형

가중치를 바꿀 때 손실이 어떻게 변하는지를 산·골짜기 지형처럼 그린 것. 울퉁불퉁하면 학습이 어려워요.

앙상블 Ensemble

여러 모델의 답을 합쳐 더 정확하게 만드는 기법. (배깅 = 여러 개 만들어 평균/투표, 소프트 보팅 = 확률 평균, 하드 보팅 = 다수결)

TTA Test Time Augmentation

시험 볼 때 사진 한 장을 여러 방식으로 변형해 여러 번 보고 평균 내는 기법. 정확도를 약간 높여요.

🔁 RNN · LSTM · GRU 용어 (순서 보는 AI)

시계열 Time series

시간 순서대로 쌓이는 데이터. 예: 매일의 주가, 기온.

시퀀스 Sequence

순서가 있는 데이터 묶음. 예: 문장 속 단어들.

은닉 상태 Hidden State

RNN이 지금까지 본 내용을 적어둔 ‘메모’. 다음 단계로 계속 넘겨줘요. LSTM에선 ‘단기 기억’ 역할.

셀 상태 Cell State

LSTM이 정보를 멀리까지 실어 나르는 ‘장기 기억 벨트’.

게이트 Gate

정보를 얼마나 통과시킬지 0~1로 조절하는 수도꼭지. 0 = 잠금, 1 = 활짝.

파라미터 공유 Parameter Sharing

RNN이 매 시점에 ‘같은 가중치’를 반복해서 쓰는 것.

BPTT 시간 역전파

RNN의 역전파. 시간을 거꾸로 거슬러 올라가며 가중치 고칠 양을 계산해요.

기울기 소실 Vanishing Gradient

역전파에서 작은 값이 계속 곱해져 기울기가 0에 가까워지는 것. 그러면 앞쪽(과거)이 학습을 못 해요.

장기 의존성 Long-term Dependency

멀리 떨어진 과거 정보를 기억해 써야 하는 상황. RNN은 이걸 잘 못해요(그래서 LSTM·GRU 등장).

Wxh / Whh / Why RNN 가중치

Wxh = 현재 입력 반영, Whh = 이전 기억 반영, Why = 출력 만들기. RNN의 세 가중치.

AR AutoRegressive

현재 값을 자신의 과거 ‘값(values)’으로 예측하는 옛날(통계) 시계열 모델.

MA Moving Average

현재 값을 과거의 ‘오차(errors)’로 설명하는 통계 모델. AR과 헷갈리지 마세요: AR=값, MA=오차!

ARMA / ARIMA 통계 모델

ARMA = AR + MA 결합(데이터가 안정적이어야 함). ARIMA = ARMA에 ‘차분’을 더해 추세·계절성 제거.

정상성 Stationary

시간이 지나도 평균·변동 폭이 일정한 성질. 통계 시계열 모델의 전제 조건.

Encoder-Decoder 인코더-디코더

입력 시퀀스를 요약(encode)했다가 새 시퀀스로 풀어내는(decode) 구조. 번역에 사용.

01Convolutional Neural Network

CNN 합성곱 신경망 · 사진을 보는 AI

핵심 한 줄: 사진을 한꺼번에 보지 말고, 작은 영역을 조금씩 훑으며 “위치별 특징”을 찾는다.
🐣 쉽게 말하면 사진 전체를 통째로 외우는 게 아니라, 작은 돋보기를 들고 그림 위를 훑으며 “여기 눈, 여기 코, 여기 털” 하고 부분 부분의 특징을 찾는 AI예요.

왜 이렇게 할까?

사진을 그냥 옛날식 신경망(FC layer, 완전연결층)에 넣으면 픽셀을 하나하나 따로 봐서 “눈은 코 위에 있다” 같은 위치 정보가 사라집니다. 사람도 강아지를 볼 때 픽셀을 세지 않고 “둥근 눈, 까만 코, 큰 귀” 같은 부분 모양을 보죠. CNN은 그걸 흉내 낸 겁니다. 픽셀 위치를 마구 섞으면 사람도 못 알아보듯, 이미지엔 위치별 패턴이 핵심이에요.

입력 데이터 = 3차원 텐서

이미지는 (높이 Height, 너비 Width, 채널 Channel) 3차원입니다. 채널 = 색이에요. 흑백은 채널 1개, 컬러(RGB)는 3개. 예: 높이4·너비4·RGB면 텐서 모양은 (4, 4, 3).

CNN의 3대 부품

① 합성곱(Convolution) 층 — 특징을 찾는 “도장”

작은 사각형 도장(필터 = 커널 Kernel)을 사진 위에서 왼→오, 위→아래로 움직이며 찍습니다. 도장이 닿는 자리마다 “여기 세로줄 있네”처럼 특징을 잡아내요. 그 결과 그림을 특징 맵(Feature Map)이라고 합니다.

🐣 쉽게 말하면 필터(커널) = 무늬 찾는 도장이에요. 이 도장을 그림 위에서 한 칸씩 옮겨 찍으면, 도장이 찾는 무늬(예: 세로줄)가 어디에 있는지가 새 그림(특징 맵)으로 나와요. 이 도장 속 숫자를 AI가 스스로 바꿔가며 배웁니다.
  • 학습되는 것 = 필터 안의 숫자들(weight)과 bias. AI가 “어떤 특징을 찾아야 잘 맞히지?”를 스스로 알아냅니다.
  • 한 필터는 한 특징만 잡으니, 여러 종류 필터를 써서 여러 특징을 뽑고, 그 결과들을 깊이(Depth, z축) 방향으로 쌓아 특징 맵을 만듭니다.
  • 컬러(RGB) 입력이면 필터의 채널 수도 입력에 맞춰 3개가 됩니다(앞 층의 채널 수에 항상 맞춤).

Conv 와 FC의 차이 (서술형 단골)

  • 주변(일부 영역)만 연결 → 지역성(Locality): 위치 정보를 잃지 않음(선택과 집중).
  • 같은 필터를 사진 전체에 재사용 → 가중치 공유(Weight sharing): 적은 수의 weight로 위치별 특징을 찾음.
항목Fully Connected (FC)CNN (Conv)

파라미터 수많음적음 (가중치 공유)
이미지 처리비효율적효율적
공간(위치) 정보손실됨유지됨

학습되는 층 vs 학습 안 되는 층 (객관식 단골)

층학습 파라미터?이유

Fully Connected Layer✅ O연결 가중치를 학습

함정 주의 “학습 파라미터가 없는 층은?” → 답은 Pooling Layer. 단골 오답입니다.

출력 크기 계산 — Stride 와 Padding

스트라이드(Stride, S) = 도장을 몇 칸씩 건너뛰며 움직이는지. 패딩(Padding, P) = 가장자리 정보를 살리려고 입력 테두리에 0을 둘러주는 것.

시험 포인트 · 공식 암기 출력 가로/세로 = (입력크기 − F + 2P) / S + 1  (F = 필터 크기). 출력 채널 수 D₂ = K (필터 개수).
예) 입력 (6,6,1) + 3×3 필터 1개(P=0, S=1) → 출력 (4,4,1). “새 특징 맵 + 크기 축소”.
계산 예제 (단답형 대비): 입력 32×32, 필터 5×5, P=0, S=1 → (32 − 5 + 2·0) / 1 + 1 = 28 → 출력 28×28. 필터를 64개 쓰면 출력은 28×28×64.
🐣 쉽게 말하면 도장을 찍고 나면 그림이 살짝 작아져요. 얼마나 작아지는지를 알려주는 게 저 공식이에요. 스트라이드(도장을 몇 칸씩 옮기나)와 패딩(테두리에 0을 둘러 크기 유지)만 알면 끝. 공식만 외우면 단답형은 그냥 맞혀요.

② 풀링(Pooling) 층 — 요약·압축

특징 맵을 작게 줄이는 단계. 보통 2×2 칸에서 가장 큰 값만 남기면 Max Pooling, 평균을 내면 Average Pooling(그 외 L2-norm pooling 등).

🐣 쉽게 말하면 풀링 = 그림 요약하기. 4칸을 1칸으로 줄여 그림을 작고 가볍게 만들어요. 가장 센 값만 남기면 Max, 평균이면 Average. 여기엔 배울 숫자가 없어요(그냥 고르기만 함) — 시험에 “학습 안 하는 층?” 하면 답이 풀링이에요.

풀링의 역할 3가지(단답형): ⓐ 지역적 불변성(위치가 조금 틀어져도 같은 걸로 인식) ⓑ 정보 요약 ⓒ 차원 축소(계산량 ↓).

풀링 종류하는 일
Max Pooling구역에서 최댓값 선택 (가장 흔히 사용)
Average Pooling구역의 평균값 선택
L2-norm Pooling구역 값들의 L2 노름 사용

→ 공통점: 특징 맵 크기를 줄이는 역할이며, 학습 파라미터는 없음.

③ 완전연결(FC) 층 — 최종 판단

지금까지 뽑은 특징 맵들을 한 줄로 쭉 펴고(Flatten), 일반 신경망 + Softmax로 “강아지 0.94, 고양이 0.01 …”처럼 최종 분류를 합니다. Softmax는 출력값을 합이 1인 확률로 바꿔주는 함수예요.

🐣 쉽게 말하면 앞에서 특징을 잔뜩 모은 다음, 마지막에 “그래서 이게 뭐야?”를 판단하는 단계예요. 모아둔 특징을 한 줄로 펴고(Flatten), 보통 신경망에 넣어 “강아지 94%!”처럼 확률로 답을 내요.

꼭 기억할 직관

  • 특징의 계층: 입력에 가까운 층은 낮은 수준(선·모서리), 깊어질수록 높은 수준(눈·얼굴 같은 의미 있는 패턴)을 잡습니다.
  • 수용 영역(Receptive Field): 출력 한 칸이 “원본 이미지의 얼마나 넓은 범위”를 보는지. Conv를 여러 번 통과할수록 이 범위가 넓어집니다.
  • 3×3 두 번 vs 5×5 한 번: 같은 수용 영역이지만 3×3 두 번이 ① 파라미터 적고(3·3·2=18 < 25) ② 비선형성 ↑ → 보통 더 유리.
  • 1×1 합성곱의 의미: 공간은 안 보고 채널 간 정보를 섞어 채널 수(차원)를 조절 → 파라미터 절감용으로 자주 씀.
02대표 아키텍처

유명한 CNN 모델 4개 ImageNet 챔피언들

매년 ImageNet(ILSVRC) 대회에서 1000종 사진 분류 경쟁이 열렸고, 2012년 AlexNet 이후 CNN이 휩쓸며 이제는 사람보다 잘 맞힙니다. 평가 지표는 보통 Top-5 오류율(예측 상위 5개 안에 정답이 있는지).

2012

AlexNet

딥러닝 시대를 연 모델. ReLU 첫 본격 사용. 과적합 방지로 데이터 증강(flip·crop)·드롭아웃(0.5) 사용. 8개 층.

2014

VGGNet

작은 3×3 필터만 깊게 쌓음(padding=1, stride=1). 풀링할 때마다 채널 수 2배. 단순·일관된 구조가 특징.

2014

Inception (GoogLeNet)

“1×1·3×3·5×5 중 뭐가 좋을지 모르니 다 써보고 옆으로 붙이자(concat)”. 1×1 conv로 연산량↓, 보조 분류기로 기울기 소실 완화.

2015

ResNet

핵심은 스킵 연결(skip-connection). 아주 깊게(152층) 쌓아도 학습되게 만든 혁신. 1등 달성.

Inception Net 더 알기

  • 여러 크기 필터 결과를 깊이(z축)로 concat → 크기를 맞추려고 stride=1 고정 + padding 조절.
  • 1×1 conv로 차원 축소: 3×3 통과 전에 채널을 미리 줄이면 파라미터가 확 줄어요(예: 89,856 → 11,712). “1×1을 먼저” 해야 효과가 큼.
  • 보조 분류기(Auxiliary classifier): 중간에서도 손실을 계산해 기울기 소실 완화. L_total = L1 + 0.3·(L2 + L3).
  • 마지막은 GAP(Global Average Pooling)로 7×7×512 → 1×1×512처럼 채널별 평균 1개로 압축 → 과적합 방지, FC 의존 줄임.
  • 성능: 7개 모델 앙상블 + TTA(Test Time Augmentation)(이미지 1장을 144장으로 변형해 평균) → Top-5 오류 6.67%.
앙상블 상식: 여러 모델 결과를 합치는 기법. 하드 보팅=다수결, 소프트 보팅=확률 평균. Inception/ResNet은 배깅(Bagging) + 소프트 보팅으로 분산(variance)을 줄여 성능을 높였습니다.

ResNet 더 알기 — 가장 출제 빈도 높음

문제 인식: ReLU+BN으로 기울기 소실을 해결했는데도, 모델이 너무 깊으면 오히려 학습이 안 됨(언더피팅). 깊은 망은 얕은 망을 그대로 흉내(나머지 층은 항등 매핑)낼 수 있으니 더 잘해야 정상인데, 훈련 오류(training error)조차 더 컸어요. 이 현상을 공식 용어로 학습 저하(Degradation) 문제라고 부릅니다. (나중에 밝혀진 원인: 깊어질수록 Loss Landscape(손실 지형)가 울퉁불퉁해짐.)

객관식 함정 · Degradation ≠ Overfitting:
· 학습 저하(Degradation) = 훈련 오류부터 더 큼(학습 자체가 안 됨). ResNet이 풀려는 문제.
· 과적합(Overfitting) = 훈련은 잘되는데 테스트만 나쁨. 원인이 완전히 다름!
🐣 쉽게 말하면 층을 아주 깊게 쌓으면 오히려 학습이 안 되는 문제가 있었어요. 해결책은 입력을 ‘지름길’로 건너뛰어 그대로 더해주는 것(스킵 연결). 그러면 각 층은 전부 새로 만들 필요 없이 ‘조금 바뀌는 부분(차이)’만 배우면 돼서 훨씬 쉬워져요. 이게 ResNet의 전부예요.
  • 왜 잘되나? 만들고 싶은 이상적 출력 H(x)가 입력과 비슷할 때(H(x) ≈ x), 보통 가중치는 0 근처로 초기화되니 F(x)≈0만 만들면 자동으로 H(x)≈x가 됩니다. 즉 “변화량(잔차, residual)만 학습”하면 돼서 쉬워져요. 그래서 이름이 Residual Learning → ResNet.
  • 직관: 깊은 망에서는 한 층이 다 바꾸려 하지 말고 조금씩만 바꿔 나가라고 AI에게 귀띔하는 셈. (실제로 깊을수록 각 층 출력 편차 std가 작음.)
  • 보통 2~3개 층을 건너뜀(한 층만 건너뛰면 효과 적음).
  • 병목(Bottleneck) 구조: 50층 이상에서 1×1로 채널↓ → 3×3 → 1×1로 채널↑(예 256→64→256). 파라미터 절감 (1×1=채널 조절, 3×3=공간 정보).
  • 구조: 처음·끝 빼고 풀링 대신 stride=2로 크기 축소, 끝은 GAP. 실선=identity, 점선=projection(1×1로 크기·채널 맞춤) shortcut.
  • 너무 깊게(1202층) 가면 이번엔 과적합(overfitting)이 일어나 110층보다 나빠짐.
시험 포인트 · ResNet은 이 3개로 기억
  • ① Skip-connection(스킵 연결) — 입력 x를 건너뛰어 더함: 출력 = x + F(x)
  • ② Residual Learning(잔차 학습) — 변화량(차이)만 학습 → 학습이 쉬워짐
  • ③ 효과 — 아주 깊은 망을 학습 가능하게 + 기울기가 지름길로 흘러 기울기 소실 완화
※ ‘2~3층 건너뜀’은 부가 설명. 위 3개를 우선 외우세요.
03Recurrent Neural Network

RNN 순환 신경망 · 순서를 기억하는 AI

핵심 한 줄: 지금 입력만 보지 말고, 바로 전 단계에서 기억한 내용도 함께 보고 다음을 예측한다.
🐣 쉽게 말하면 RNN은 ‘메모’를 들고 다니는 AI예요. 문장을 단어 하나씩 읽으면서 “지금까지 무슨 얘기였지”를 메모에 적어두고, 다음 단어를 볼 때 그 메모를 같이 봐요. 그래서 순서가 중요한 데이터(문장·주가 등)에 강합니다.

왜 필요한가?

“나는 밥을 ___” 다음 단어를 맞히려면 앞 단어 순서가 중요하죠. 주가·날씨·센서값처럼 시간 순서대로 들어오는 데이터(시계열, time series)도 마찬가지. 보통 신경망은 입력을 따로따로 보지만, RNN은 이전 시점 정보를 “기억”해서 다음으로 넘깁니다.

딥러닝 이전 시계열 모델(객관식·단답형 대비 — 영문 키워드 매칭):
모델정확한 정의핵심 영문 키워드
AR (AutoRegressive)변수의 현재 값을 자신의 과거 값들을 기반으로 예측past values (과거 값)
MA (Moving Average)관측값과 과거의 잔차 오차 간의 관계에 초점residual errors (잔차 오차)
ARMAAR + MA 결합. 데이터가 정상성(stationary)을 가져야 함stationary
ARIMAARMA에 차분(differencing) 단계 추가 → 추세·계절성 제거differencing
함정 주의 AR = 과거 ‘값(values)’, MA = 과거 ‘오차(errors)’. 이 둘을 바꿔치기한 보기가 오답으로 자주 나옵니다.

작동 방식 — “메모”를 이어받기

RNN에는 은닉 상태(hidden state) hₜ라는 “메모”가 있어요. 매 시점마다:

새 메모 hₜ = f( 지금 입력 xₜ + 바로 전 메모 hₜ₋₁ )  →   출력 yₜ = g( hₜ )

식으로는 hₜ = tanh(Wxh·xₜ + Whh·hₜ₋₁), ŷₜ = softmax(Why·hₜ). 전 단계 기억을 계속 이어 흘려보내서 이름이 “순환(Recurrent)”입니다.

시험 포인트 · 핵심 수식 (단답형 빈칸 최빈출)

hₜ = tanh( Wxh·xₜ + Whh·hₜ₋₁ )

ŷₜ = softmax( Why·hₜ )

빈칸으로 나오기 쉬워요: hₜ = tanh( ____·xₜ + ____·hₜ₋₁ ) → 답: Wxh, Whh.

가중치 3종의 역할 (단답형 단골)

파라미터역할
Wxh현재 입력(xₜ)을 반영
Whh이전 시점 정보(hₜ₋₁)를 반영 ← 순환의 핵심
Why현재 시점의 출력(yₜ)을 생성
시험 포인트 · 반드시 암기 RNN의 핵심 특징 = 파라미터 공유(Parameter Sharing). Wxh · Whh · Why는 모든 시점에서 똑같은 값을 재사용한다. (CNN의 ‘가중치 공유’와 짝지어 기억하세요.)

RNN 구조의 종류 (입력→출력 개수로 구분) — 객관식 단골

구조입력 → 출력대표 예시
Many-to-One여러 입력 → 출력 1개감성분석 / 여러 시점 센서값 → 제품 정상·불량 판정
One-to-Many입력 1개 → 여러 출력이미지 캡셔닝(사진 1장 → 설명 문장)
Many-to-Many입력마다 출력품사 태깅(POS Tagging)
Many-to-Many (Encoder-Decoder)입력 시퀀스 → 출력 시퀀스기계 번역 (= Many-to-One + One-to-Many)
암기 팁 “예시 → 구조 맞히기”가 자주 나옵니다. 감성분석=Many-to-One, 이미지 캡셔닝=One-to-Many, 품사태깅=Many-to-Many, 번역=Encoder-Decoder.

학습 과정

  • ① 순전파(Forward)로 손실 계산 → ② 역전파(Backward)로 기울기 계산 → ③ 가중치 업데이트(학습률 η만큼, 경사하강법).
  • 손실 함수: 회귀 문제는 MSE(평균제곱오차), 분류 문제는 Cross Entropy(교차 엔트로피).
시험 포인트 · BPTT RNN의 역전파는 일반 역전파와 구분해 BPTT (Backpropagation Through Time)라고 부릅니다.
  • RNN의 역전파 방법으로, 시간축을 거슬러(과거 시점 방향으로) 기울기를 전달한다.
  • 이때 한 시점의 영향뿐 아니라 이전 시점들로부터 전해진 영향까지 모두 더해 Whh·Wxh의 기울기를 구한다.
  • 시퀀스가 길어질수록 같은 항이 반복 곱해져 기울기 소실(Vanishing Gradient)이 발생 → 장기 의존성 문제로 이어진다.

RNN의 결정적 약점 (LSTM·GRU가 나온 이유)

장기 의존성 문제(Long-term dependency): 순서가 너무 길어지면 맨 앞 정보가 뒤로 갈수록 점점 희미해져 사라진다. → 한마디로 “RNN은 기억력이 짧다.”
기울기 소실(Gradient Vanishing)이 생기는 흐름:
① 역전파(BPTT)를 시간축으로 반복 → ② 작은 기울기 값이 계속 곱해짐 → ③ 값이 거의 0이 되어 앞쪽(과거) 층까지 전달되지 않음 → ④ 먼 과거를 학습 못 함 → 그래서 LSTM·GRU가 등장.
🐣 쉽게 말하면 RNN의 메모는 금방 흐려져요. 문장이 길어지면 맨 앞 내용을 까먹는 거죠. “0.1 × 0.1 × 0.1 …”처럼 작은 값이 자꾸 곱해져 거의 0이 되기 때문이에요. 이 깜빡임을 고치려고 나온 게 LSTM과 GRU입니다.
04Long Short-Term Memory

LSTM 기억력을 보강한 RNN

핵심 한 줄: RNN의 짧은 기억력을 고치려고, “무엇을 기억하고 무엇을 잊을지” 조절하는 문(gate)을 달았다.
🐣 쉽게 말하면 LSTM은 장기 기억 노트(셀 상태)를 따로 가지고 다녀요. 그리고 3개의 수도꼭지(게이트)로 “이건 잊어, 이건 새로 적어, 이건 꺼내 써” 하고 정리해요. 덕분에 긴 문장에서도 중요한 건 안 까먹어요.

두 가지 기억

  • 은닉 상태 hₜ = 단기 기억(Short-term)
  • 셀 상태 cₜ = 장기 기억(Long-term) — 정보를 멀리까지 실어 나르는 “컨베이어 벨트”

3개의 문(Gate) — 단답형 최빈출

게이트 = 정보를 얼마나 통과시킬지 정하는 0~1 사이의 가중치예요. 0이면 “완전히 차단”, 1이면 “전부 통과”. 각 게이트는 식이 같은 꼴이고(σ(Wxh·xₜ + Whh·hₜ₋₁ + b)) 서로 다른 파라미터를 써서 다른 값을 냅니다. (σ = 시그모이드, 0~1로 눌러주는 함수)

게이트하는 일
망각 게이트 (Forget, fₜ)과거 셀 상태에서 버릴 정보를 정함 (0이면 다 잊고, 1이면 다 기억)
입력 게이트 (Input, iₜ)지금 정보 중 새로 저장할 것을 정함
출력 게이트 (Output, oₜ)셀 상태를 은닉 상태로 얼마나 내보낼지 정함

업데이트 순서 (서술형 대비)

  1. 게이트 3개 계산 (각각 σ 적용).
  2. 임시 셀 상태 c̃ₜ = tanh(...) 만들기(현재 입력+과거 요약).
  3. 셀 상태 갱신: cₜ = fₜ ⊗ cₜ₋₁ ⊕ iₜ ⊗ c̃ₜ → 잊을 건 잊고, 더할 건 더함 (⊗ = 원소별 곱).
  4. 은닉 상태 갱신: hₜ = oₜ ⊗ tanh(cₜ).
시험 포인트 · 활성화 함수(단답형 빈칸 대비)
  • 게이트 3개(망각·입력·출력)는 0~1 비율을 정해야 하므로 시그모이드(σ, sigmoid) 사용.
  • 임시 셀 상태 c̃ₜ(새 기억 후보)는 −1~1 범위가 필요하므로 tanh 사용.
  • 최종 은닉 상태도 tanh(cₜ)를 거쳐 출력 게이트와 곱해짐.
Peephole connection(참고): 게이트가 입력·단기기억뿐 아니라 장기기억(cell state)까지 엿보게(peep) 개선한 변형.
05Gated Recurrent Unit

GRU LSTM을 가볍게 만든 버전

핵심 한 줄: LSTM과 비슷한 성능인데 구조를 단순화해 더 가볍다. 게이트 3개 → 2개, 기억 2종 → 1종.
🐣 쉽게 말하면 GRU는 LSTM의 간소화 버전이에요. 수도꼭지를 3개 → 2개로 줄이고, 기억 노트도 하나로 합쳤어요. 성능은 비슷한데 더 가볍고 빨라요. “LSTM 다이어트 버전”이라고 기억하면 돼요.

무엇이 줄었나

항목LSTMGRU
게이트 수3개 (망각·입력·출력)2개 (업데이트 zₜ · 리셋 rₜ)
Cell State있음 (셀 상태 + 은닉 상태)없음 (은닉 상태로 통합)
파라미터 수많음적음
학습/추론 속도느림빠름
  • 업데이트 게이트 zₜ: LSTM의 망각+입력 게이트 역할을 하나로. “과거를 얼마나 유지하고, 새것을 얼마나 받을지” 한 번에 결정.
  • 리셋 게이트 rₜ: 과거 정보를 얼마나 무시(reset)할지 결정.
  • 은닉 상태 갱신: hₜ = (1 − zₜ) ⊗ hₜ₋₁ ⊕ zₜ ⊗ h̃ₜ — 과거와 새 정보를 비율로 섞음.
시험 포인트 · 흐름 한 줄 RNN(기본·기억력 짧음, 기울기 소실) → LSTM(게이트 3개 + 셀 상태로 기억 보강) → GRU(게이트 2개로 간소화, 가벼움). 셋 다 “순서 데이터”용이고, LSTM·GRU는 장기 의존성 문제를 완화한 모델.

전체 발전 흐름 (서술형 2번 대비)

“왜 이 모델들이 차례로 나왔는가”를 한 흐름으로 엮으면 서술형에서 강합니다.

서술형 한 문단 템플릿 “CNN은 이미지의 위치별 특징을 뽑고, RNN은 순서 데이터를 처리한다. 그러나 RNN은 시퀀스가 길어지면 기울기 소실로 장기 의존성 문제가 생긴다. 이를 LSTM이 셀 상태와 3개의 게이트로 완화했고, GRU는 LSTM을 게이트 2개로 간소화해 더 가볍게 만들었다.”
시험 범위 밖(참고만): 두 번째 자료 뒤쪽의 Seq2Seq · Attention · Transformer는 교수님 메일상 “GRU 파트까지”라 출제 범위가 아닙니다. 다만 “RNN의 한계(고정 길이·정보 손실)를 극복하려 나온 후속 모델”이라는 큰 맥락만 알아두면 충분합니다.
최종 암기

시험 직전 30초 치트시트

  • CNN: 필터로 위치별 특징 추출. 합성곱→풀링→FC(Flatten+Softmax). 출력크기 (W−F+2P)/S+1.
  • Conv vs FC: 지역성(Locality) + 가중치 공유 → 적은 weight로 위치 정보 보존.
  • 풀링 3역할: 불변성·요약·차원축소. Max=최댓값, Avg=평균.
  • AlexNet=ReLU·드롭아웃 첫 사용 / VGG=3×3만 깊게 / Inception=여러 필터 concat+1×1로 절감 / ResNet=skip-connection(잔차 학습)으로 초깊은 망 가능.
  • RNN: hₜ = tanh(Wxh·xₜ + Whh·hₜ₋₁). 가중치 Wxh·Whh·Why를 모든 시점 공유. 약점 = 장기 의존성/기울기 소실.
  • LSTM: 셀상태(장기)+은닉상태(단기), 게이트 3개(망각·입력·출력).
  • GRU: 게이트 2개(업데이트·리셋), 기억 통합, 더 가벼움.
  • 관계: RNN → LSTM → GRU.

16. CNN이 일반 완전연결(FC) 신경망과 다른 점을 ‘지역성’과 ‘가중치 공유’ 개념을 포함해 설명하시오.

모범답안 보기
핵심 답안: ① 지역성(Locality) — FC는 모든 픽셀을 한꺼번에 연결해 위치 정보가 사라지지만, CNN은 작은 영역(주변)만 연결해 “위 정보를 잃지 않고” 위치별 특징을 학습한다. ② 가중치 공유(Weight sharing) — 같은 필터를 이미지 전체에 반복 적용하므로, 적은 수의 가중치만으로 어디에 있든 같은 패턴을 찾아낼 수 있다(필터가 가진 패턴을 찾아 스캔). 결과적으로 파라미터가 훨씬 적고, 풀링과 함께 쌓으면 앞쪽은 단순한 특징, 뒤쪽은 복잡한 특징을 단계적으로 추출한다.

17. RNN의 장기 의존성 문제가 무엇이며, LSTM이 이를 어떻게 완화하는지 게이트 구조를 들어 설명하시오.

모범답안 보기
핵심 답안: RNN은 이전 시점의 은닉 상태를 이어받아 순서 정보를 반영하지만, 시퀀스가 길어지면 역전파(BPTT) 과정에서 기울기가 반복 곱해지며 0에 수렴하는 기울기 소실이 일어나, 먼 과거 정보를 학습하지 못한다(장기 의존성 문제). LSTM은 정보를 길게 실어 나르는 셀 상태(cell state)를 따로 두고, ① 망각 게이트로 과거 정보 중 버릴 것을, ② 입력 게이트로 새로 저장할 것을, ③ 출력 게이트로 내보낼 것을 0~1 값으로 조절한다. 그 결과 중요한 정보는 오래 유지하고 불필요한 정보는 버려, 긴 시퀀스에서도 기억을 안정적으로 보존해 문제를 완화한다.

A2. AR 모델과 MA 모델의 차이로 옳은 것은?

  1. AR=과거 오차 기반, MA=과거 값 기반

  3. 둘 다 이미지 처리 모델
  4. 둘 다 차분(differencing)을 사용
정답 보기
② — AR=past values, MA=residual errors. 바꿔 쓴 ①이 단골 오답.
